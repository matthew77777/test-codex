# Simple E-Commerce Site

This example uses [Next.js](https://nextjs.org/) to provide a very small e-commerce demo with an in-memory cart. It includes two pages:

- `/` – lists products with an **Add to Cart** button
- `/cart` – shows items currently in the cart

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
